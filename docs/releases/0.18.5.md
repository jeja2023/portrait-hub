# 影鉴 0.18.5 发布说明

- 发布日期：2026-07-29
- 发布类型：视频结果预览与控制台接口定义修复补丁
- API 兼容性：继续使用 `/v1`；公开路由和 OpenAPI 基线不变；新增的控制台专用定义接口不进入公开 OpenAPI
- 数据兼容性：数据库 schema、持久化格式和迁移策略不变，不需要数据迁移

## 版本摘要

0.18.5 修复视频任务详情和实时视频流解析结果在状态持久化后无法显示帧图片的问题。任务与流事件仍会在落盘时剥离 Base64 图片正文，控制台改为使用分析归档 ID 重新加载公开缩略图；归档不可用或没有可见图片时继续使用内存结果，避免覆盖仍然有效的预览。

本版本同时修复调试台“接口定义”页对公开 `/openapi.json` 的错误依赖。生产环境仍可关闭 Swagger、ReDoc 和公开 OpenAPI 文档，具备 `access:read` 权限的控制台会通过不进入公开契约的 `/v1/console/openapi` 获取完整定义，并可下载 `openapi.json`。

## 主要变更

### 视频任务与视频流预览

- `FrameGrid` 支持按分析归档 ID 异步恢复帧缩略图，并使用请求序列保护快速切换详情时的并发响应。
- 视频任务使用确定性的 `archive_video_{job_id}` 归档 ID；视频流使用最新解析完成事件中的 `archive_id`。
- 只有归档包含可见图片时才替换当前结果；归档读取失败、缺失或仅包含帧元数据时保留内存预览。
- 新增组件回归测试，覆盖归档图片恢复和无可见归档图片时的回退行为。

### 控制台接口定义

- 新增受 `require_api_token` 与 `access:read` 保护的 `/v1/console/openapi`，响应使用统一成功外层并设置 `Cache-Control: no-store`。
- 控制台专用接口通过 `include_in_schema=False` 排除在公开 OpenAPI 之外，不改变既有公开契约基线。
- 调试台从受保护接口读取 154 条路径、180 个接口操作，并以鉴权后的响应生成“下载完整定义”文件，不再直接打开公开 `/openapi.json`。
- 后端回归锁定“公开文档关闭、控制台定义可用”的安全边界。

## 升级步骤

1. 备份 `.env`、`runtime-state`、分析归档数据库、对象存储和当前镜像清单。
2. 拉取 `0.18.5` 并确认版本：

```bash
git fetch origin
git pull --ff-only origin main
grep -F 'version = "0.18.5"' pyproject.toml
```

3. 执行发布检查并重建 API、Console 和视频/流 worker 镜像：

```bash
python -m pytest -q tests/test_release_version.py tests/test_support_matrix.py tests/test_api_contract_02_http_security.py
python tools/portrait_support_matrix.py --json
npm ci
npm run console:check
docker compose -p portrait-hub build --pull
docker compose -p portrait-hub up -d --remove-orphans
```

4. 验证视频任务详情、视频流详情和调试台“接口定义”页。生产配置可继续保持 `ENABLE_API_DOCS=false`，此时 `/openapi.json` 应为 404，而已鉴权的控制台定义页应正常加载。

## 回退

0.18.5 不包含数据迁移，可以成套回退到 0.18.4 的 API、worker 和 Console 镜像。回退不会修改既有分析归档，但 0.18.4 控制台在进程重启或外部 worker 写入后仍可能无法恢复视频帧预览，且生产关闭 `/openapi.json` 时接口定义页会再次不可用。
