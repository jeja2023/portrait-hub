# 影鉴 0.18.2 发布说明

- 发布日期：2026-07-27
- 发布类型：Console Next 表格与分页一致性补丁版本
- API 兼容性：继续使用 `/v1`；公开路径、请求/响应契约和 OpenAPI 基线无破坏性变更
- 数据兼容性：数据库 schema 和持久化数据格式不变，不需要数据迁移
- SDK 支持：Python 稳定支持，Node 维护支持，Go/Java 实验性参考实现
- 发布结论：仓库内前端一致性优化与自动化验证已完成；真实模型、目标环境容量/故障演练与人工审批状态不变

## 版本摘要

0.18.2 在 0.18.1 平台性能与交付补丁基线上统一 Console Next 的数据表格和分页体验。该版本不增加公开业务接口，不改变认证、租户/项目隔离、控制状态或数据库语义。

全项目 23 个页面、42 个数据表格面已完成静态复核。SLA 定义与模型影子结果补齐标准分页，图片归档与分析结果改用全局游标分页控件，配置中心桌面端和移动端共用同一标准表格。

## 数据表格一致性

- 38 个原生表格全部使用全局 `data-table`，4 个 Element Plus 表格继续继承全局边框、单元格间距和表头规格。
- 服务质量 SLA 定义与模型注册影子结果使用 `useTablePagination` 和 `DataTablePagination`，按分页偏移显示连续序号。
- 页面中不存在直接使用 `ElPagination` 的实现，分页布局、每页数量和页码交互由全局组件统一提供。
- 新增源码一致性门禁，持续扫描原生表格类、业务页分页组件和本次修复的关键模板契约。

## 游标分页与响应式表格

- 图片分析归档和分析结果归档移除页面私有“加载更多”，统一使用全局组件的 `hasMore`、`loadingMore` 与 `load-more` 契约。
- 人员库和视频任务删除不再使用的 `.load-more` 私有样式，页面私有加载更多标记与样式归零。
- 配置中心删除 700px 以下的独立卡片模板，所有视口使用同一 `ElTable` 数据源和分页状态。
- 配置中心宽表不再固定左右列；窄屏在表格容器内横向滚动，避免固定列占满可视区域或遮挡中间字段。

## 升级步骤

1. 记录当前提交、镜像摘要和 `.env` 备份。本补丁不要求停止业务写入或执行数据库迁移。
2. 拉取代码并确认版本：

```bash
git fetch origin
git pull --ff-only origin main
grep -F 'version = "0.18.2"' pyproject.toml
```

3. 重新构建并部署 API 与 Console Next 静态资源，避免新旧 `index.html`、manifest 和哈希资源混用。
4. 验证 `/health`、`/ready` 和控制台登录后，重点抽查服务质量、模型注册、图片分析、分析结果与配置中心。
5. 执行版本、支持矩阵和前端门禁：

```bash
python -m pytest -q tests/test_release_version.py tests/test_support_matrix.py
python tools/portrait_support_matrix.py --json
npm run check
```

## 回退边界

- 0.18.2 没有数据库 schema 或数据格式迁移，可以直接回退到已归档的 0.18.1 应用和前端镜像。
- 回退不会丢失控制面数据，但会恢复 SLA 定义与影子结果无分页、媒体归档私有加载按钮以及配置中心移动端独立卡片实现。
- 不要只回退 Console Next 的 `index.html`；HTML、manifest 和哈希静态资源必须来自同一次构建。
